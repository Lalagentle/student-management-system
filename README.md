Student Management System
Project Description
The Student Management System is a Python desktop application developed as part of my SIWES training. It helps users manage student records through a simple graphical interface.
Features
• Add new student records
• Search for student records
• Update student information
• Delete student records
• Validate required fields
• Prevent duplicate matriculation numbers
• Store student records permanently using SQLite
Technologies Used
• Python
• Tkinter for the graphical user interface
• SQLite for database storage
• PyCharm for development
How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in PyCharm.
4. Run the main.py file.
5. Use the application window to manage student records.
Database
The application uses SQLite to store student records, allowing data to remain available after the program is closed.

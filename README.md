Student Management System
Project Description
The Student Management System is a simple Python application developed as part of my SIWES training. It helps users manage basic student records.
Features
• Add student details
• View registered students
• Search for students using their matriculation numbers
Technologies Used
• Python
• PyCharm
How to Run
1. Install Python.
2. Download this repository to your computer.
3. Open the project in PyCharm.
4. Run the main.py file.
5. Follow the instructions displayed in the terminal.
Storage
Student records are stored temporarily while the program is running. They are not saved permanently yet.
